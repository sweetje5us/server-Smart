API Отслеживания Заказов - Документация

Базовый URL: http://192.168.0.24:8080/api

1. Получение информации об отслеживании заказов
   GET /orders/tracking
   
   Ответ:
   {
     "orders": [
       {
         "orderId": "order-id",
         "status": "status",
         "trackingNumber": "tracking-number",
         "lastUpdate": "2024-03-15T14:30:00.000Z"
       }
     ]
   }

Коды ответов:
- 200: Успешное выполнение
- 500: Внутренняя ошибка сервера (включает детали ошибки в режиме разработки)

Пример запроса:
GET http://192.168.0.24:8080/api/orders/tracking

Примечания:
- API возвращает подробную информацию об ошибках в режиме разработки
- Каждый запрос логируется на сервере для отладки
