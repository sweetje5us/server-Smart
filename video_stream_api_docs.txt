API Видеостриминга - Документация

Базовый URL: http://192.168.0.24:8080/api

1. Получение токена стримера
   GET /streamertoken
   
   Ответ:
   {
     "token": "streamer-token-value"
   }

Коды ответов:
- 200: Успешное выполнение
- 500: Внутренняя ошибка сервера

Пример запроса:
GET http://192.168.0.24:8080/api/streamertoken
